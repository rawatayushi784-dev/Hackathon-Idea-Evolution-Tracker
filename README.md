# 🚀 Hackathon Idea Evolution Tracker

## 📌 Introduction
Hackathon Idea Evolution Tracker is a C++-based project designed to organize, compare and improve hackathon ideas. It helps users track idea modifications and maintain a history of how their original ideas evolve over time.

## 🛠️ Technologies Used
- **Language:** C++
- **Concepts:** Data Structures and Algorithms (DSA)
- **Data Structures:** Vectors and Linked Lists
- **Tools:** VS Code
- **Other Concepts:** File Handling, String Manipulation and Modular Programming

## ✨ Key Features
1. **Idea Management:** Add and view hackathon ideas.
2. **Keyword-Based Search:** Find existing ideas using relevant keywords.
3. **Similarity Checking:** Compare ideas based on keyword matching.
4. **Idea Evolution Tracking:** Record improvements and maintain revision history.

## ⚙️ Working Process
1. The user starts the application and accesses the main menu.
2. New hackathon ideas are added and stored in the application.
3. Users can view existing ideas or search using relevant keywords.
4. The system compares ideas to identify similarities through keyword matching.
5. Users can improve existing ideas while maintaining their original concepts.
6. File handling stores current ideas and their revision history for future access.
