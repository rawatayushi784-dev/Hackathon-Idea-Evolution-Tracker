# 🚀 Hackathon Idea Evolution Tracker

## 📌 Project Introduction

The **Hackathon Idea Evolution Tracker** is a C++-based project designed to help users organize, compare, and improve their hackathon ideas. It maintains a record of ideas and tracks how they evolve through different improvements over time.

The main objective of this project is to help users identify similarities between existing ideas, understand potential improvements, and maintain a history of changes rather than replacing the original idea completely.

## 🛠️ Technologies Used

- **Programming Language:** C++
- **Concepts:** Data Structures and Algorithms (DSA)
- **Data Structures:** Vectors, Linked Lists
- **String Processing:** Keyword extraction, text normalization and comparison
- **File Handling:** File reading and writing
- **Modular Programming:** Header files (.hpp) and source files (.cpp)
- **Development Environment:** VS Code

## ✨ Features

1. **Add New Ideas:** Allows users to enter and store new hackathon ideas.
2. **View All Ideas:** Displays the list of previously submitted ideas.
3. **Search Ideas:** Searches for ideas using keywords.
4. **Similarity Checking:** Compares ideas using keyword-based matching to identify related or similar concepts.
5. **Idea Improvement:** Helps users record improvements and modifications to existing ideas.
6. **Revision History:** Maintains previous versions and records changes made to ideas.
7. **Save Data:** Stores idea information in `ideas.txt`.
8. **Load Data:** Retrieves previously saved ideas and information.
9. **History Management:** Uses `history.txt` to maintain previous revisions and improvement records.

## ⚙️ Working Process

### Step 1: Add an Idea
The user enters a new hackathon idea with its relevant details.

### Step 2: Store Idea Information
The application stores the submitted idea in its data structure so it can be accessed and managed.

### Step 3: Search and Compare Ideas
The system searches existing ideas using keywords and compares their content to identify similarities.

### Step 4: Improve the Idea
The user can modify an existing idea by adding new features or making improvements.

### Step 5: Maintain Revision History
Whenever an idea is improved, its previous version and related change information can be maintained in the revision history.

### Step 6: Save and Load Data
The application uses file handling to save and retrieve information.

- `ideas.txt` – Stores current idea information.
- `history.txt` – Stores previous revisions and improvement records.
